# PubScreen 📺✨

> **Serverless Digital Signage System for Public Mall Displays**  
> Autonomous, resilient, and powered by GitHub as a Headless CMS.

---

## 🏛️ System Architecture

```
                       ┌────────────────────────────────────────┐
                       │           GitHub Repository            │
                       │           (Headless CMS)               │
                       └──────────────────┬─────────────────────┘
                                          │
                git push (.mp4 in /videos or images in /sponsors)
                                          │
                                          ▼
                       ┌────────────────────────────────────────┐
                       │     GitHub Actions Workflow            │
                       │     (.github/workflows/update-media)   │
                       └──────────────────┬─────────────────────┘
                                          │
                     Scans folders & generates media-list.json
                     Auto-commits back with [skip ci]
                                          │
                                          ▼
                       ┌────────────────────────────────────────┐
                       │              GitHub Pages              │
                       │          (Static Web Hosting)          │
                       └──────────────────┬─────────────────────┘
                                          │
                    Polls media-list.json every 5 minutes
                    Caches video & logos with Service Worker
                                          │
                                          ▼
                       ┌────────────────────────────────────────┐
                       │           Mall Display Screen          │
                       │     (Autonomous Offline Player)        │
                       └────────────────────────────────────────┘
```

## 🚀 How It Works (Headless CMS Workflow)

1. **Adding / Removing Videos:**
   - Drop any `.mp4`, `.webm`, or `.mov` file into the `/videos/` directory and commit/push to `main`.
2. **Adding / Removing Sponsors:**
   - Drop any `.png`, `.jpg`, or `.svg` logo into `/sponsors/` and commit/push to `main`.
3. **The GitHub Action (`update-media.yml`):**
   - Automatically detects changes in `/videos/` or `/sponsors/`.
   - Scans both folders and builds an updated `media-list.json`.
   - Commits and pushes `media-list.json` back to `main` with `[skip ci]`.
4. **Automatic Screen Refresh:**
   - The screen in the mall polls `media-list.json` every **5 minutes**.
   - Upon detecting new media, it smoothly enqueues the new videos and starts cycling the updated sponsors without interrupting the screen or requiring a manual refresh.

## 🖥️ Screen Features

- **Full-Screen Video Player:**
  - Double-buffered `<video>` architecture (`#bg-video-a` and `#bg-video-b`) with opacity crossfading to eliminate black flashes between videos.
  - Automatically loops back to the start when the end of the playlist is reached.
  - **30-Minute Safety Watchdog:** If any video exceeds 30 minutes, it automatically transitions to the next item to prevent frozen or looped content from dominating the screen.
- **Permanent Top Corner Branding:**
  - Top-Left: **Passi** logo in a frosted glass capsule with contrast drop shadow.
  - Top-Right: **L'agora** logo.
  - Top-Center: Real-time clock widget formatted for mall visitors.
- **Glassmorphic Sponsor Bar:**
  - Fixed at the bottom of the screen with `backdrop-filter: blur(24px)`.
  - Transparent white aesthetic (`rgba(255, 255, 255, 0.85)`).
  - Center: **QR Code** with active scan-line animation, linking directly to `links.html`.
  - Right Flank: **Dynamic Sponsor Stage** fading a new sponsor logo in every **10 seconds** with a progress bar.
- **Offline Resilience (`sw.js`):**
  - Caches `index.html`, `style.css`, `app.js`, permanent logos, and media files.
  - Features an advanced **HTTP 206 Partial Content Range parser** inside the Service Worker so that browsers (Chrome, Safari) can stream cached `.mp4` video files offline without stalling.
  - If the mall's Wi-Fi drops, the display transitions to offline mode silently and continues playing cached videos on loop.
- **Mobile QR Landing Page (`links.html`):**
  - Linktree-style page optimized for mobile phone browsers when shoppers scan the QR code.
  - Features the Passi logo, location tag, and styled buttons:
    1. *"Follow us on Instagram"*
    2. *"Visit Official Website"*

## 🛠️ Local Development & Testing

You can run the digital signage locally using any HTTP server:

```bash
# Using Node's npx serve
npx serve .

# Or using Python 3
python -m http.server 8080
```

Open your browser to:
- **Digital Signage Display:** `http://localhost:8080/public/index.html`
- **QR Mobile Landing Page:** `http://localhost:8080/public/links.html`

To simulate an internet loss, open Chrome DevTools > **Network** tab > select **Offline**. The screen will display the discreet *"Mode Hors-ligne (Actif)"* indicator and continue playing video and cycling sponsors seamlessly from cache.
